LLM Knowledge Benchmarks — Cheat Sheet

Quick-reference · Knowledge capability · benchmark evolution · MMLU · TruthfulQA · GPQA · MMLU-Pro · HLE

1-PAGE REFERENCE

1Knowledge capability

Knowledge: how much world knowledge an LLM retained in its parameters from training.

It covers facts, concepts, and relationships—not all of intelligence or product usefulness.

2Why evaluate knowledge?

  • Compare model capability across common tasks
  • Track progress across model generations
  • Find gaps: facts, truthfulness, depth
  • Shortlist candidates before custom evaluation
Without context: a single score can be misleading.

3Benchmark definition

Benchmark: a standardized dataset, task, scoring method, and protocol used to measure a particular capability.

No single “LLM IQ” exists—different tests target different skills.

44-step evaluation process

1. Choose capability→2. Select test→3. Fixed protocol→4. Score + interpret

5Why benchmarks evolve

  • Saturation: scores reach the ceiling
  • Contamination: public test data enters training
  • Dataset flaws: incorrect or ambiguous answers
  • Coverage gaps: a test misses an important behavior

6MMLU: the starting point

A major standardized benchmark for breadth of knowledge: roughly 14,000 multiple-choice questions across 57 subjects.

202057 subjects~14k MCQsaccuracy

7MMLU: limitation

Because items are public, later models can encounter the questions or answers during training. High scores eventually stop differentiating models.

Saturation: performance is near the ceiling, so rank differences tell less.

9Evolution path

MMLU→TruthfulQA→GPQA→MMLU-Pro→HLE

Every next test addresses a limitation found in previous tests.

10TruthfulQA

Tests whether models repeat common misconceptions or provide truthful, informative answers.

Key distinction: knowledge recall ≠ truthfulness.

11Why truthfulness matters

  • Internet training data includes false claims.
  • Models can learn popular misconceptions.
  • Correct-sounding answers may still be untrue.
  • TruthfulQA probes this reliability gap.

12SimpleQA

Short, open-ended factual questions used to assess factuality, hallucination rate, and calibration.

MCQEasy to score; can reward guessing.
Open-endedMore realistic; grading is harder.

13GPQA

Google-Proof Q&A: ~500 extremely difficult graduate-level science questions in biology, physics, and chemistry.

Purpose: test depth of expert knowledge—not only broad recall.

14MMLU-Redux

Not a benchmark. It is an audit showing that around 6–8% of MMLU items have issues such as wrong or missing reference answers.

Lesson: evaluate the benchmark dataset too.

15MMLU-Pro

  • Harder MMLU-style benchmark
  • More reasoning-oriented items
  • 10 answer options—not 4
  • ~12,000 questions; fewer disciplines
Goal: reduce guessing and make success require reasoning.

16Humanity's Last Exam

HLE: frontier-level benchmark with ~2,500 research-level questions across ~100 subjects.

2025~100 subjectsbreadth + depth

17HLE caveats

  • Not representative of everyday tasks
  • Mainly English
  • Some visual-input questions
  • LLM grading can vary
  • Selection bias can affect difficulty

20Selection checklist

21Mental model

Don't ask: “Which model is strongest?” Ask: “Which model performs well on my task, in my language and domain, within my cost and latency limits?”

Rule: Benchmark scores shortlist; custom evals decide.
